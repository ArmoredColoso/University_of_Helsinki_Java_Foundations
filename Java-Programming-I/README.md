# University of Helsinki: Java Programming I (Solutions)

This repository contains my personal solutions, code exercises, and notes from the University of Helsinki - Java Programming I course. 

## What I Practiced & Learned
* **Core Java Fundamentals:** Control flow, methods, arrays, lists, and hash maps.
* **Object-Oriented Programming (OOP):** Classes, constructors, encapsulation, inheritance, and object composition.
* **Testing & Debugging:** Writing and running unit tests using TMC (Test My Code) / JUnit principles.

## Structure
* `part01-part02/` - Basic input/output and repetition
* `part03-part05/` - Lists, objects, and OOP fundamentals
* `part06-part07/` - User interface design and larger logic flows
